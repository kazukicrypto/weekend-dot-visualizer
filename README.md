# weekend-dot-visualizer

ブラウザで動く小さなアプリ・ゲーム集（GitHub Pages で配信）。

公開URL: https://kazukicrypto.github.io/weekend-dot-visualizer/

## 収録ゲーム

- 🎲 **ダイス・ディフェンス** (`tower/`) — ランダムダイス風タワーディフェンス。ダイスを召喚し、同じ目を合成して強化。5属性で敵を自動攻撃し、生存ウェーブを competes。
- 🐉 **ドラゴン・ブレイズ** (`shooter/`) — ガチャ・装備・お供ドラゴン付きのモバイル縦シューティング。進むほど難化。
- 💖 **ふれあい3Dガール** (`3d-girl-touch/`) — 3Dキャラとふれあうモバイル最適化アプリ。
- ⚔️ **騎士ドラ風 戦闘プロトタイプ** (`knight-dragon/`) — バトル／装備／ガチャの戦闘プロトタイプ。

各ゲームのタイトル画面から、ほかのゲームやゲーム一覧へ移動できます。

いずれも単一HTML／Canvasで依存ライブラリなし・オフライン動作します。
