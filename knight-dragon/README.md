# 騎士ドラ風 戦闘プロトタイプ

サービス終了したスマホRPG「騎士とドラゴン」（株式会社リプレーション、2013年）の戦闘システムを参考にした、HTML + Canvas + Vanilla JS による戦闘プロトタイプです。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

```sh
# どちらでもOK
open index.html
# または簡易サーバー
python3 -m http.server 8000
```

## 操作

| キー | アクション |
| --- | --- |
| `1` | 剣で攻撃（AP1） |
| `2` | 槍で攻撃（AP1） |
| `3` | ハンマーで攻撃（AP1） |
| `Space` | ガード（タイミング判定） |

スマホ・タブレットでは画面下部のボタンをタップしてください。

## 実装した「騎士ドラ」要素

- **AP制バトル**：技を使うとAPを消費、時間で自動回復
- **武器三すくみ**：剣 / 槍 / ハンマーで弱点ダメージ＆PP増加
- **PP（ピヨ）システム**：攻撃で蓄積、満タンで敵がスタン → 攻撃が必ず会心
- **タイミング型ガード**：
  - `MIRACLE`（残り0.07秒以内）：完全無効化＋HP回復＋AP回復
  - `JUST`（残り0.20秒以内）：90%軽減＋AP回復
  - `GUARD`（残り0.7秒以内）：60%軽減
  - 早すぎ：効果なし
- **コンボ**：ガード成功で蓄積、敵PPに追加ダメージ
- **3体連戦**：ゴースト → ドラゴン → ゴーレム
- **必殺技コンボ**：3回の武器入力パターンで必殺技発動（画面下のCOMBOスロットで進行確認）
  - `剣→剣→剣` … 剣聖斬（3ヒット）
  - `槍→槍→槍` … 貫穿撃
  - `ハンマー→ハンマー→ハンマー` … 大地砕
  - `剣→槍→ハンマー` … 聖騎士奥義（4ヒット, 最大ダメージ）
  - `ハンマー→槍→剣` … 英雄連舞
- **サウンド**：WebAudioによるチップチューン風SE＋BGM。画面右上のボタンで切替

## ファイル

- `index.html` — UIレイアウト
- `style.css` — スタイル（モバイル対応）
- `game.js` — ゲームロジック・描画
