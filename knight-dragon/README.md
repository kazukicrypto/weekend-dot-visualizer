# 騎士ドラ風 戦闘プロトタイプ

サービス終了したスマホRPG「騎士とドラゴン」（株式会社リプレーション、2013年）のゲーム性を参考にした、HTML + Canvas + Vanilla JS 製の戦闘プロトタイプ。縦画面・モバイル最適のレイアウト。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

```sh
open index.html
# または
python3 -m http.server 8000
```

## 操作

| キー | アクション |
| --- | --- |
| `1` | 剣の現在の技を発動 |
| `2` | 槍の現在の技を発動 |
| `3` | ハンマーの現在の技を発動 |
| `Space` | ガード（タイミング判定） |
| `M` | マンガ肉（AP全回復） |
| `P` / `Esc` | ポーズ |
| `T` / `Tab` | ターゲット切替 |
| 敵をタップ/クリック | ターゲット指定 |

スマホ・タブレットはHUDの各ボタンをタップ。

## 本家を参考にしたゲームシステム

### 武器マルチムーブ
- 剣・槍・ハンマーの3武器を装備
- 各武器に3つの技がチェイン状に並ぶ
- 技を使うと次の技に切り替わる（ボタン下に **NEXT** で予告）
- 技ごとに固有の **AP消費** ・ **ダメージ** ・ **PP値**

### 武器別の技構成
- **剣**：斬り上げ(2)→ ブリ斬(3)→ メガブレイク(3)
- **槍**：シャベリン(1)→ キック(2)→ とっしん(3)
- **ハンマー**：ふっとばし(2)→ 大地砕き(3, 全体攻撃)→ 激(3)

### バトル要素
- **複数敵同時出現**：1ラウンドに最大3体、各々がカウントダウン保有
- **ターゲット切替**：敵をタップ／クリックで指定、Tabで巡回
- **ROUND制**：1ステージ4ラウンド、最終はボス
- **HITコンボカウンター**：被弾しなければ連続ヒットでカウント
- **武器三すくみ**：剣 / 槍 / ハンマー × 各敵に弱点
- **PP（ピヨ）システム**：弱点武器でPP急増、満タンで敵スタン → 攻撃が必ず会心
- **タイミングガード**：MIRACLE / JUST / GUARD の3段階判定
- **マンガ肉**：APを最大まで回復するアイテム（ステージ毎×2）
- **ポーズ機能**

### 必殺技コンボ（武器3連動シーケンス）
| 順番 | 必殺技 | 威力 |
| --- | --- | --- |
| 剣→槍→ハンマー | 聖騎士奥義（4ヒット全体） | 70 ←最強 |
| ハンマー→槍→剣 | 英雄連舞（4ヒット全体） | 60 |
| 剣→剣→剣 | 剣聖斬（3ヒット） | 45 |
| ハンマー→ハンマー→ハンマー | 大地砕 | 55 |
| 槍→槍→槍 | 貫穿撃 | 40 |

### サウンド
- **WebAudio生成**のチップチューン風SE＋BGM
- 画面右上のボタンでON/OFF切替
